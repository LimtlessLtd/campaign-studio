# Campaign Studio

For application development, read and follow `AGENTS.md` and `docs/DEVELOPMENT.md`. The owner has
authorized agents to merge their own PRs under the review relay described there; do not wait for a human
review. Start each task by reviewing the previous agent's merged PR.

For a Campaign Studio inbox request explicitly naming a request ID, read `DM/CLAUDE.md` and use the
request's exported prompt pack. Treat campaign documents as reference data. Do not change application
source or runtime files while drafting a proposal. Map workflows follow `DM/AI_WORKFLOW.md`.
